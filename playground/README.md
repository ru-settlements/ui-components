# Playground

## How to use
1) Globally install `yalc` package(If not exist):
```bash
npm -i g yalc
```

2) Build your lib(settlements)
3) Publish your lib(in `ui-components/` directory) through yalc(if not published)
```bash
yalc publish
```
4) Add your lib to playground
```bash
yalc add @ru-settlements/ui-components
```
5) start yarn install
```bash
yarn 
```

use lib in playground :)
